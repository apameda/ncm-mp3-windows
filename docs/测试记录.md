## Mac 成品验收

Mac 版使用已校验 Electron 44.7.2 和对应架构 FFmpeg，两种 Mac 归档的解压、严格临时签名、权限与 Framework 符号链接检查通过。Apple 芯片成品已用原生窗口和系统文件夹选择器转换两首 NCM（内含 MP3 / FLAC）及一首普通 FLAC，界面显示三首 100%、整体成功 3；随后三份 MP3 均通过完整解码、中文标签和源文件 SHA-256 不变核对。Intel Mac 未实机运行；本地签名不等于 Apple 公证。

## 普通 FLAC 新增验收

直接添加 `.flac` / `.FLAC`，真实执行 320 / 256 / 192 kbps、44.1 kHz 转码，保留中文歌名、歌手和专辑。原始 FLAC 字节与 mtime 均不变；验证伪文件头、损坏帧、重名、两阶段取消均符合预期。文件夹扫描和原生选择器接受 FLAC，可与加密文件混合批量；LRC 按用户要求不处理。Apple 芯片最终功能版本的原生界面混合批量验收通过。

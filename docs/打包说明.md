# Windows 绿色版打包

构建目标为 Windows 10/11 x64，用户解压 ZIP 后双击 `NCM批量转MP3.exe`，不需要安装 Python、Node.js 或 FFmpeg。软件转换时只使用本地文件与随包 FFmpeg；以下下载仅发生在开发者构建阶段。

## 构建环境与命令

- macOS 或 Linux；Node.js 20 或更新版本；系统 `unzip`。不使用 npm 运行时依赖、Wine、全局打包器或 Windows 编译器。
- 在项目根目录运行 `node scripts/package-windows.mjs`。首次构建从下列固定上游下载依赖；后续复用 `.cache/windows` 内经过同样 SHA-256 检查的缓存。
- 完全离线构建：先放齐下表的四个文件，再运行 `node scripts/package-windows.mjs --offline`。其他显式缓存目录可用 `--cache-dir /absolute/cache/path` 指定。
- 输出 `dist/NCM批量转MP3-Windows-x64.zip` 与同名 `.sha256`。脚本先对 ZIP 内所有条目做完整性检查，再交付最终文件。构建中间文件自动清理。
- ZIP 写入器的离线自检：`node scripts/verify-zip.mjs`，覆盖 UTF-8 中文路径、空文件、分块二进制及解压 CRC 检查。

## 包结构与许可

按 [Electron 官方手动打包方法](https://www.electronjs.org/docs/latest/tutorial/application-distribution)将应用放入 `resources/app` 并重命名 `electron.exe`。全部 DLL、ICU 数据、V8 快照、locale 与 Chromium 资源均保留，不仅复制 EXE。

```text
NCM批量转MP3-Windows-x64/
  NCM批量转MP3.exe
  LICENSE-electron
  LICENSES.chromium.html
  README.md
  THIRD_PARTY_NOTICES.md
  第三方源码.md
  RELEASE_NOTES.md
  LICENSE
  BUILD-MANIFEST.json
  docs/
    第三方源码.md
    测试记录.md
    screenshots/
  licenses/ffmpeg/{LICENSE,README.txt}
  resources/app/
    package.json
    src/
    resources/ffmpeg.exe
    README.md
    THIRD_PARTY_NOTICES.md
    第三方源码.md
    LICENSE
  ...完整 Electron 运行环境
```

Electron 自身采用 MIT 许可，保留发行包原始 `LICENSE` 为 `LICENSE-electron`，并保留 Chromium 等组件完整声明。Gyan 明确将其静态构建标为 GPLv3；打包时逐字保存其原始 `LICENSE` 和 `README.txt` 到 `licenses/ffmpeg/`。FFmpeg 9.0.2 的上游源码定位为 [946fcce07b](https://github.com/FFmpeg/FFmpeg/commit/946fcce07b)。[第三方源码指引](第三方源码.md)列出原始构建配置、37 项依赖版本、官方源码入口与尚未核实的材料；它不声称是完整的 Corresponding Source 归档。

打包脚本将整个 `docs/` 目录复制到发行包根目录，保留 README 的截图和说明链接；同时把源码指引复制为根目录和 `resources/app/` 下的 `第三方源码.md`，并在根目录附上 `RELEASE_NOTES.md`。本项目自己的应用源代码随绿色版交付；第三方源码仍按指引定位，本脚本不会额外下载或打包完整第三方源码树。

## 验证边界

打包脚本可在 macOS 验证归档校验值、内容布局与 ZIP 完整性，但不会执行 Windows EXE。Windows 端还需完成一次解压启动、中文路径批量转换、取消与失败继续的实机验收。当前包未签名，不宣称通过代码签名或 SmartScreen 信誉验证。

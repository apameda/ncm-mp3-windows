## Mac 发行组件

Apple 芯片版使用 Martin Riedl FFmpeg 9.0.2，Intel 版使用 ffmpeg-static b6.1.1 所分发的 6.1.1-tessus。固定下载、配置与来源证据见 `打包说明.md`，完整原始许可和构建来源信息随包保存在 `licenses/ffmpeg/`。FFmpeg 主源码分别为 [946fcce07b](https://github.com/FFmpeg/FFmpeg/commit/946fcce07b) 与 [n6.1.1](https://github.com/FFmpeg/FFmpeg/tree/n6.1.1)，原构建者脚本见 [Martin Riedl](https://git.martin-riedl.de/ffmpeg/build-script) 及 [ffmpeg-static](https://github.com/eugeneware/ffmpeg-static/blob/b6.1.1/download-binaries/index.sh)。这些入口不冒称完整静态依赖的对应源码归档；尚未独立还原所有上游脚本精确修订和依赖输入。
